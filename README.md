# Laugh Track: The Crypto Trading Joke Contest

[![Built for make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on [make.fun](https://make.fun).

## The joke

> I bought the dip so many times my exchange sent me a loyalty card: buy ten dips, get the eleventh crash free.

One original line about crypto trading life, under the 200-character cap.

## Run

```sh
python3 main.py
```

`main.py` prints the single joke line to stdout. Deterministic, offline,
standard library only — the same output on every run.
